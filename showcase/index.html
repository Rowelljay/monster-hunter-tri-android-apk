First time? Here’s the setup.
  1. Install the official APK.Use the GitHub download above. This native app installs separately from the older MH4U - Rowell app.
  2. Extract the game archive.Use a 7Z-capable extractor. Put the extracted folder in normal phone storage, for example MH4U_Native, outside Android/data. Allow space for both the archive and its extracted files.
  3. Choose the complete game folder.Open MH4U → Give permission and choose folder. Allow file access, return, then enter the folder containing MH4U.cci, MH4U_update.cia, libmh4u_code_native.so, its .id and mods. When it says “The game is here,” tap Use this folder. Select the folder itself, not the archive or the storage root.
  4. Start the game.Wait for preparation to finish. Choose No when asked about the Nintendo 3DS Circle Pad Pro attachment; the app handles swipe-camera and controller input itself.

The USA game, 1.3.0 update and code library must match this native app and its code-changing mods. A newer APK may need a newly generated library. The developer’s full setup guide explains the required files and how to build the library.

Keeping your progress when updating

Save inside the game first. In Gear → Menu Options → Export save, make a backup before updating. An official update with the same app identity and signing key normally keeps its data; uninstalling or clearing app data removes app-owned saves.

Progress from an older Azahar-based app needs a separate save import. Use a copy of your save through Import save; its control settings belong to the older app.

Native port, Azahar and known bugs

Both run the Nintendo 3DS version of MH4U. Azahar emulates its CPU; this port recompiles the game’s CPU code for Android and uses its own runtime with Vulkan graphics. Parts of that runtime are derived from Azahar and Citra.

A native port can still have compatibility bugs. Startup was checked on a POCO F5; full quest, save/reopen and multiplayer testing remain separate checks. A sharper picture or higher FPS does not guarantee every feature works.
