Set up the native port
  1. Install the official APK.Use the GitHub download above. This native app installs separately from the customized Azahar edition.
  2. Extract the game archive.Use a 7Z-capable extractor. Put the extracted folder in normal phone storage, for example MH4U_Native, outside Android/data. Allow space for both the archive and its extracted files.
  3. Choose the complete game folder.Open MH4U → Give permission and choose folder. Allow file access, return, then enter the folder containing MH4U.cci, MH4U_update.cia, libmh4u_code_native.so, its .id and mods. When it says “The game is here,” tap Use this folder. Select the folder itself, not the archive or the storage root.
  4. Start the game.Wait for preparation to finish. Choose No when asked about the Nintendo 3DS Circle Pad Pro attachment; the app handles swipe-camera and controller input itself.

The USA game, 1.3.0 update and code library must match this native app and its code-changing mods. A newer APK may need a newly generated library. The developer’s full setup guide explains the required files and how to build the library.

Keeping your progress when updating

Save inside the game first. In Gear → Menu Options → Export save, make a backup before updating. An official update with the same app identity and signing key normally keeps its data; uninstalling or clearing app data removes app-owned saves.

Progress from an older Azahar-based app needs a separate save import. Use a copy of your save through Import save; its control settings belong to the older app.

Native port, Azahar and known bugs

Both run the Nintendo 3DS version of MH4U. Azahar emulates its CPU; this port recompiles the game’s CPU code for Android and uses its own runtime with Vulkan graphics. Parts of that runtime are derived from Azahar and Citra.

A native port can still have compatibility bugs. Startup was checked on a POCO F5; full quest, save/reopen and multiplayer testing remain separate checks. A sharper picture or higher FPS does not guarantee every feature works.

Set up the customized Azahar app
  1. Install this edition’s APK.Use Download customized APK above. The Native port tab provides a different installer. For updates, save in-game and install over this edition without uninstalling or clearing its data.
  2. Download your game.Choose either Ziperto or Romsfun above and use the USA version. Romsfun’s single ZIP / 7Z can be added directly. Ziperto’s split files need the manual extraction step below.
  3. Add the game.From Home, tap Add game and choose the single ZIP / 7Z or a decrypted .3ds, .cci or .cxi image. Wait for copying or extraction to finish, then tap Play game. Keep the app open; Cancel removes an incomplete import. A main-game .cia, an entire folder or a native code library cannot be used here.
  4. Choose a screen layout.Keep the small second screen visible for dialogue and quest choices. Adjust touch controls and combos, then tap Save & play.

Using Ziperto’s three-part download? Download all three matching USA parts from the same set into one folder. Extract part 1 once; the extractor reads the remaining parts automatically. Add the resulting game image, not the separate parts.

Add game copies or extracts the image directly into this app’s storage, keeping your original download. Allow space for the archive and extracted game. Once import and the first game launch work, you can remove the download copy. RAR, password-protected, split or unsupported archives need manual extraction. Normal play needs only the game; optional live FPS features require separate setup with a matching USA v1.3.0 update and code library.

Ordinary emulation does not need the native port’s code library. The two apps use different runtimes and settings; their native libraries are not interchangeable. Performance depends on the phone.

Transfer progress between the two apps

Save inside MH4U first. Export a copy from the source app and keep a backup of the destination’s progress.

In the customized app, open Settings → Saves → Import save → From another MH4U app. Enter the actual dated save folder containing sdmc, tap Use this folder, and review the confirmation. Import replaces the saved progress and restarts the app.

A compatible USA save was successfully transferred from Native to this app on a POCO F5. This is a manual transfer, not automatic sync. Control layouts belong to each app and do not transfer with game progress.
